# OpenCart Manual Testing Project

## Project Overview
This project covers manual testing of the OpenCart e-commerce application.

## Objectives
- Validate core e-commerce functionalities.
- Verify expected results against actual results.
- Document test execution status.
- Record and track defects.

## Testing Scope
- User registration and login
- Product search and product details
- Shopping cart
- Checkout
- Order-related functionality

## Test Artifacts
- Test Scenarios
- Detailed Test Cases
- Test Execution Report
- Bug Report

## Tools Used
- OpenCart
- Microsoft Excel
- Jira
- XAMPP / MySQL

## Project Outcome
Test cases and execution results are documented in Excel. Defects are recorded in the bug report.
